ALWAYS renders because it is the SSE swap target (id/sse-swap "pending-config-{node_key}"). Without a draft it renders empty, and the first edit swaps a populated banner into the shell that was already there. A conditional shell would mean the very first frame after an edit had nowhere to land -- which is the 404 the B4 browser check was written to catch. **hx-swap is innerHTML, not outerHTML**, and the body lives in partials/pending_config_body.html — which is what the SSE frame carries. Discard is destructive but bounded and reversible by retyping, so it confirms with hx-confirm rather than a typed dialog -- contrast the Node-removal dialog, which is neither.
