{# Alarm activation pop-up shell — the always-present swap target for SSE event `alarm-toast` (sse.rs `handle_alarm_nudge`). Included once by layout/base.html, inside the app shell's sse-connect wrapper (sse-swap targets must be descendants of the connected element), so every authenticated page shows pop-ups. daisyUI `toast toast-end` fixed-positions the stack bottom-right; `pointer-events-none` keeps the fixed container from swallowing clicks — each toast restores `pointer-events-auto` on itself. The script below is the single owner of the toast lifecycle. htmx still appends every incoming fragment (hx-swap="beforeend"), but the MutationObserver immediately captures the node into a sessionStorage- mirrored store and re-renders the visible view from that store: - CONTINUITY: the store carries an absolute expiry per toast (20 s from first appearance), so a page navigation replays what's still live with its remaining lifetime, and a dismissed toast stays dismissed. - COLLAPSE: up to two toasts render as-is; from three up, only the most recent renders plus a "+ N more" chip linking to /alarms — toast width, centered label, neutral fill so it reads as a counter under the stack instead of a second alert (label supplied by data-more-label — the only i18n this script needs). Dismissing or expiring the visible one promotes the next newest. - MUTE: `window.proximosAlarmToasts.mute()` stamps now+1h into localStorage (per-browser, shared across tabs — a 'storage' listener clears other tabs' stacks too), clears the stack, and incoming fragments are dropped while the stamp is in the future. `.unmute()` lifts it. The toast's own mute button and the Alarm pop-ups card on pages/notifications.html (whose Alpine component `alarmToastMute` is registered here, next to the state it fronts) are the two callers. Expiry is the store's job alone — the fragment carries no self-remove timer (its ✕ just removes the node; the observer turns that into a store removal). Re-rendering re-inserts nodes, so the observer is detached around render() to keep its own DOM writes out of the event stream. #}
